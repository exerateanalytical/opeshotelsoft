# French / English UI

French is the default; each user's choice is saved in `users.locale` (switch in the Topbar, the login page and Profile).

## Add a string

1. Add the key to **both** `lang/fr.json` and `lang/en.json` (a test checks that both files have the same keys).
   Use `<area>.<screen>.<thing>` keys, for example `hr.leave.approve`. Placeholders use `:name`.
2. In React:

```tsx
import { useT } from '@/lib/i18n';
const t = useT();
<h1>{t('hr.leave.title')}</h1>
<p>{t('hr.leave.days_left', { count: 3 })}</p>
```

3. In PHP, `__('hr.leave.title')` reads the same JSON files (the active locale is set per request).

A missing key renders as the key itself, so it is easy to spot.

Workstreams do not own `lang/*.json`: list your new keys (FR and EN text) in your report and the lead merges them,
or keep a local `const FR/EN` map in your page until then.

Sidebar labels are keys too (`nav.*`), defined in `app/Http/Navigation.php`.
