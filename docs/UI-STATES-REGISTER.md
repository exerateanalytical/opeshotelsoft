`<ApiState query={q}>` (resources/js/Components/ui/ApiState.tsx) gives all three in one line. The check is a static heuristic: GAP means the source shows no evidence of that state, not that it was tested by hand.

Global safety net: `useApi` shows a friendly toast (FR/EN, request reference, no raw exception) when a page never reads `.error`, so a failed read is never silent even on a GAP page.

## Shared building blocks

- `useApi` returns `{ data, error, loading, reload, updatedAt }`; `error` is an `ApiError` (status 0 for timeout and network failure). 30 s read timeout.
- `<ApiState query={q} variant empty>` replaces the content with skeleton, error or empty; `<QueryStatus query={q}>` is the drop-in line for pages that keep their own markup.
- `<LoadingState variant="list|table|cards|detail|form">`, `<EmptyFor kind>` / `<NoResults onReset>`, `<ErrorState error onRetry>`, `<PermissionState roles>`, `<FieldError id message>` (always reserves one line).
- `describeError()` in `lib/apiErrors.ts` maps problem types and statuses to FR/EN text (`lang/{fr,en}/states.json`); domain messages of 400, 409 and 422 are kept when they read as plain prose, 5xx, 403 and 404 never show server text.
- Pages that are not listed above use no data calls (static or Inertia-prop pages).
